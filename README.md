# Snehal Chauhan Portfolio

A responsive one-page professional portfolio built with Angular and TypeScript.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Start locally

```bash
npm install
npm start
```

Open `http://localhost:4200/` in a browser.

## Production build

```bash
npm run build
```

The production files are generated in `dist/snehal-portfolio/`.

## GitHub Pages

The `Deploy portfolio to GitHub Pages` workflow builds and deploys the site automatically whenever changes are pushed to `main`. The Pages build uses the repository path as its base URL:

```bash
npm run build:pages
```
