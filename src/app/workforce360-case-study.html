PERSONAL PROJECT / ENGINEERING CASE STUDY

Workforce360:
from APIs to AI-assisted workflows.

A full-stack MVP exploring workforce management workflows with .NET, Angular, SQL Server, and MCP-based AI integration.

PROJECT TYPEPersonal MVP
MY ROLEFull-stack developer
BACKEND.NET 10 / ASP.NET Core
FRONTENDAngular

01 / THE PROBLEM

Managing connected workforce information

Employee, department, and leave-related information belongs to connected workflows. I built this project to explore how these workflows can be supported through a full-stack web application while practicing modern backend design and frontend integration.

02 / THE SOLUTION

A full-stack application

Developed an ASP.NET Core Web API and Angular frontend, connected to SQL Server through Entity Framework Core, with JWT-based authentication.

03 / AI & MCP

Exploring tool-based AI integration

Integrated an AI workflow with MCP-based discovery and invocation of supported application tools. This explores an additional interaction path alongside the standard application APIs.

04 / HIGH-LEVEL ARCHITECTURE

How the application is connected

05 / ENGINEERING WORK

What I implemented

  • REST API development with ASP.NET Core
  • Angular frontend integration
  • SQL Server data access using EF Core
  • JWT-based authentication
  • OpenAI and MCP integration exploration
  • Docker-based development and xUnit tests

06 / LEARNINGS

What I learned

  • Connecting frontend workflows to API contracts
  • Understanding authentication boundaries
  • Keeping AI integration separate from core workflows
  • Designing and testing backend functionality
  • Exploring MCP tool discovery and invocation

07 / CURRENT SCOPE & NEXT STEPS

An MVP with room to grow

Workforce360 is a personal MVP, not a complete enterprise HRMS. Its current scope covers selected employee, department, and leave-related functionality. Future improvements include broader automated test coverage, stronger validation and error handling, CI/CD, monitoring, and carefully authorized MCP tools.
